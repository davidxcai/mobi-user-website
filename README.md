### Dependencies

- Supabase

- TanStack Query
- React Router
- Mantine Form

### Setup

1. Create a Supabase project.
2. Create a `.env` file and fill in your keys.

```bash
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

3. Run:

```bash
npm i
npm run dev
```
